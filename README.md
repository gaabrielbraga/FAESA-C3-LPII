# Sistema de Reservas — Hotel/Pousada (FAESA-C3-LPII)

> Projeto desenvolvido para a disciplina **Laboratório de Programação II**  
> Turma: 2HC1 · Professor: Rober Marcone Rosi

---

## Sobre o Projeto

Sistema orientado a objetos desenvolvido em **Java** para gerenciamento completo de um hotel ou pousada. O sistema contempla todo o ciclo de hospedagem — do cadastro de hóspedes ao check-out — com controle de acesso por perfil, serviço de quarto e relatórios gerenciais.

## Funcionalidades

| # | Épico | Tarefas |
|---|---|---|
| 1 | Autenticação e Controle de Acesso | Estrutura de usuários, Login, Permissões |
| 2 | Cadastro de Hóspedes | Cadastro, Consulta e histórico |
| 3 | Cadastro e Gestão de Quartos | Cadastro, Listagem, Controle de status |
| 4 | Reservas | Criação, Disponibilidade, Gestão |
| 5 | Check-in | Processo de entrada, Hospedagem ativa |
| 6 | Check-out | Encerramento, Cálculo, Comprovante |
| 7 | Serviço de Quarto | Cardápio, Pedidos, Integração financeira |
| 8 | Limpeza | Controle de limpeza, Status, Histórico |
| 9 | Relatórios Gerenciais | Ocupação, Reservas, Financeiro |
| 10 | Testes e Homologação | Testes funcionais, Aprovação final |
